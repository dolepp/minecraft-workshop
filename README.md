# minecraft-workshop

Original educational workshop with local browser tools: https://dolepp.github.io/minecraft-workshop/

Build, artifact validation and GitHub Pages deployment run exclusively in GitHub Actions. No runtime service or paid API is required for this website.

Measurements: outbound referral clicks, tool use and downloads. These are not confirmed registrations or sales.

## Analytics

Public Yandex Metrica counter ID: 114145698. Goals: aeza_click, configurator_use, template_download. No secrets are requested by local browser tools.

## Research and scope

The workshop was selected after query-intent research. Search volume is not a traffic or revenue forecast. Articles cite primary documentation and disclose limits. The website does not host user data, a game process or a Nextcloud instance.
